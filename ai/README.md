# ИИ — Мафтуна

Советы ИИ **готовы и работают** на сайте. Под советами видна надпись «✨ Советы подготовил ИИ».

## Как это устроено

- Файл `advice_ai.py`, функция `get_ai_advice(air, api_key)`.
- Модель OpenAI: **`gpt-4.1-mini`**. Она записана в переменной `MODEL` в начале файла,
  чтобы её было легко поменять.
- Приложение передаёт ИИ текущие данные: AQI, PM2.5, PM10, NO₂, температуру, влажность,
  давление и ветер.
- ИИ отвечает строго в JSON: короткие советы на русском для 4 групп и совет по проветриванию.
  Без диагнозов, лекарств и доз; для детей и при астме — осторожнее, чем для взрослых.
- Ответ ждём не дольше 15 секунд. При любой ошибке функция возвращает `None`, и приложение
  показывает советы по правилам из `backend/advice_rules.py`.
- Приложение запоминает советы на 30 минут, чтобы не тратить деньги на одинаковые запросы.
- Чата нет: человек ничего не спрашивает, советы появляются сами.

Формат входа и выхода описан в начале `advice_ai.py`. Не меняйте название функции
и ключи словаря, иначе приложение не соединится.

## Ключ

В `.streamlit/secrets.toml`, в кавычках:
```toml
AI_API_KEY = "sk-..."
```
Ключ никому не отправляем. На platform.openai.com стоит поставить месячный лимит расходов (например, 5 $).

## Как проверить

В папке проекта:
```
python tests/check_ai.py
```
Скрипт проверяет по шагам: ключ, библиотеку `openai`, ответ модели и функцию.
В конце должно быть «[4] Всё работает!» и пять советов.

Прогноз воздуха на 24 часа даёт сервис Open-Meteo, своей модели прогноза у нас нет.
