# ИИ — Мафтуна

Задача команды: в файле `advice_ai.py` написать функцию `get_ai_advice(air, api_key)`.

ИИ сам пишет короткие советы по текущим данным о воздухе и погоде
для 4 групп людей и совет по проветриванию. Чата нет — человек ничего не спрашивает.

Формат входа и выхода описан в начале `advice_ai.py`. Не меняйте название функции
и ключи словаря, иначе приложение не соединится.

Прогноз воздуха на 24 часа уже есть в приложении — его даёт сервис Open-Meteo,
делать свою модель прогноза не нужно.
