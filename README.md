# Air Control Sensors

Веб-приложение о качестве воздуха в Казахстане: показывает AQI, погоду и сразу даёт советы
для взрослых, детей, людей с астмой и спортсменов, а также когда проветривать. Знай, чем дышишь.

**Сайт:** https://air-control-sensors.streamlit.app

## Что умеет

- **4 способа выбрать место:**
  - **Город из списка** — 20 городов Казахстана; у Шымкента ещё и районы города;
  - **Район области** — все 17 областей и 166 сельских районов;
  - **Поиск** — любой город или село мира;
  - **Моё местоположение** — определяет, где вы, и показывает ваш город, район или сельский район.
- **AQI** с цветной шкалой, **погода** (температура, влажность, ветер, давление), PM2.5, PM10, NO₂.
- **Живые уличные датчики** (aqicn.org): районы берут цифру с ближайшего датчика — до 15 км
  в городе и до 60 км для сельских районов; расстояние показано в таблице. Где датчиков нет —
  расчёт модели, и это честно подписано.
- **Советы ИИ** (OpenAI) для 4 групп и по проветриванию; если ИИ недоступен — советы по правилам.
- **Графики** за 24 часа и 7 дней, прогноз на сутки.
- **Карты:** Казахстан (самый чистый и самый грязный город, рейтинг) и районы с датчиками,
  синяя точка «вы здесь».
- Без интернета на сервере — **демо-данные** с предупреждением, приложение не падает.

## Как запустить у себя

1. Установите **Python 3.12** (при установке поставьте галочку «Add python.exe to PATH»).
2. Скачайте проект:
   ```
   git clone https://github.com/RoninKaz/Air-Control-Sensors.git
   cd Air-Control-Sensors
   ```
3. Установите библиотеки и запустите:
   ```
   python -m pip install -r requirements.txt
   python -m streamlit run app.py
   ```
4. Приложение откроется в браузере (обычно http://localhost:8501).

Без ключей приложение тоже работает: данные о воздухе и погоде берутся из бесплатного
Open-Meteo. Ключи нужны только для живых датчиков и советов ИИ (см. «Ключи»).

## Ключи

Ключи хранятся в `.streamlit/secrets.toml`. **Этот файл в GitHub не загружаем.**
Пример — `.streamlit/secrets.toml.example`: скопируйте его, назовите копию `secrets.toml`
и вставьте свои ключи. Кавычки обязательны.

```toml
AI_API_KEY = "sk-..."        # OpenAI — советы ИИ
AQICN_TOKEN = "ключ_aqicn"   # живые датчики, бесплатно: aqicn.org/data-platform/token
```

На сайте ключи вставлены в share.streamlit.io → Manage app → Settings → Secrets.
Ключи никому не отправляем и в чаты не вставляем.

## Договорённости между командами (не менять без общего капитана)

**Место (place)** — словарь `{"name": "Алматы", "lat": 43.238, "lon": 76.946}`

**Бэкенд (`backend/data.py`) → всем**
- `CITIES` — 20 городов; `city_place(name)` → place
- `DISTRICTS` — районы городов (сейчас Шымкент); `district_place(city, district)` → place
- `REGIONS` — районы областей из `backend/regions.py`;
  `region_place(region, district=None)` → place (без района — центр области)
- `search_places(text)` → список place (любой город или село мира)
- `nearest_place(lat, lon)` → place по местоположению: район города, город или район области
- `get_air(place)` → словарь «что сейчас»:
  `city, aqi, time, pm25, pm10, no2, t (°C), h (%), p (гПа), w (м/с), source`
- `get_hourly(place)` → (таблица по часам `time, utc, pm2_5, pm10, no2, aqi`: 7 дней назад
  и прогноз; источник `"api"` или `"demo"`); `split_now(df)` делит её на прошлое и прогноз
- `get_cities_aqi()`, `get_districts_aqi(city)`, `get_region_aqi(region)` → AQI многих точек
  одним запросом: список `{city, lat, lon, aqi}`
- `get_stations(city, token)` → живые датчики aqicn.org вокруг города или области
  (без ключа — пустой список; датчики, молчащие больше 3 часов, отбрасываются)
- `nearest_station(lat, lon, stations, max_km)`, `stations_mean(stations)`
- `apply_stations(rows, stations, max_km)` → каждой точке цифру ближайшего датчика
  и поле `source`: «📡 …» или «🌐 модель». `STATION_MAX_KM = 15` (город),
  `REGION_STATION_MAX_KM = 60` (сельские районы)

**Бэкенд (`backend/advice_rules.py`)** — `get_rule_advice(air)` → советы по правилам

**ИИ (`ai/advice_ai.py`)** — `get_ai_advice(air, api_key)` → советы или `None`

**Формат советов** (одинаковый у правил и у ИИ):
```python
{"adults": "...", "children": "...", "asthma": "...", "sport": "...", "airing": "..."}
```

**Фронтенд (`ui.py`)** — `show_place_picker`, `show_search_results`, `show_header`, `show_aqi`,
`show_weather`, `show_advice`, `show_charts`, `show_map`, `show_districts`.

Местоположение определяет библиотека `streamlit-js-eval`: браузер спрашивает разрешение.
Работает на localhost и на сайте по https.

## Важно про данные

- **Модель Open-Meteo (CAMS)** считает воздух квадратами примерно 45 км, поэтому соседние
  районы по модели часто получают одинаковые цифры.
- **Живые датчики** точнее, но их мало: почти все — в крупных городах. Пример: в Караганде
  модель показывала AQI 51, а датчики — 121 (IQAir в то же время — 127). Именно этот пробел
  и закрывают устройства Air Control Sensors.
- Время везде — местное время выбранного места.
- Источники: Open-Meteo (воздух, погода, поиск), World Air Quality Index Project — aqicn.org
  (живые датчики), OpenAI (советы).
