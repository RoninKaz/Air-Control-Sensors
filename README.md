# Air Control Sensors 🌫️

Веб-приложение: показывает качество воздуха и погоду в 20 городах Казахстана
(и в любом городе мира через поиск) и сразу даёт советы для взрослых, детей,
людей с астмой и спортсменов. Знай, чем дышишь.

## Как запустить у себя

1. Установите Python 3.10 или новее.
2. Скачайте проект (Code → Download ZIP или через GitHub Desktop).
3. Откройте терминал в папке проекта и выполните:

```
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

4. В браузере откроется приложение (обычно http://localhost:8501).

Ключ API для данных не нужен: используем бесплатный сервис Open-Meteo.
Если интернета нет — приложение покажет демо-данные.

## Кто за что отвечает

| Файл | Команда |
|---|---|
| `app.py` | Общий капитан — соединяет всё вместе |
| `ui.py` | Фронтенд — Султан |
| `backend/data.py`, `backend/advice_rules.py` | Бэкенд — Азизбек |
| `ai/advice_ai.py` | ИИ — Мафтуна |
| `tests/` | Тестирование — Талшын |

Правило: работайте только в своём файле. Готовую работу — своему капитану,
капитаны — общему капитану.

## Договорённости между командами (не менять без общего капитана)

**Место (place)** — словарь `{"name": "Алматы", "lat": 43.238, "lon": 76.946}`

**Бэкенд → всем**
- `CITIES` — 20 городов Казахстана; `city_place(name)` → place
- `DISTRICTS` — районы городов (пока Шымкент); `district_place(city, district)` → place
- `search_places(text)` → список place (поиск любого города мира)
- `nearest_place(lat, lon)` → place по местоположению пользователя (ближайший район или город)
- `get_districts_aqi(city)` → AQI во всех районах города одним запросом
- `get_stations(city, token)` → реальные уличные датчики aqicn.org вокруг города (без ключа — пустой список)
- `apply_stations(rows, stations)` → каждому району ставит цифру ближайшего живого датчика (не дальше 15 км, `STATION_MAX_KM`)
- `get_air(place)` → словарь «что сейчас»:
  `city, aqi, time, pm25, pm10, no2, t (°C), h (%), p (гПа), w (м/с), source`
- `get_hourly(place)` → (таблица `time, utc, pm2_5, pm10, no2, aqi` по часам: 7 дней назад + прогноз, источник `"api"`/`"demo"`)
- `get_cities_aqi()` → AQI во всех 20 городах одним запросом (карта и рейтинг)
- `get_rule_advice(air)` → советы по правилам

**ИИ → общему капитану**
- `get_ai_advice(air, api_key)` → советы или `None`

**Формат советов** (одинаковый у правил и у ИИ):
```python
{"adults": "...", "children": "...", "asthma": "...", "sport": "...", "airing": "..."}
```

**Фронтенд** — функции в `ui.py`: `show_sidebar`, `show_search_results`, `show_header`, `show_aqi`,
`show_weather`, `show_advice`, `show_charts`, `show_map`, `show_districts`, `show_room_demo`, `show_footer`.

Местоположение определяется сразу при выборе «📍 Моё местоположение» — библиотека
`streamlit-js-eval` (браузер спросит разрешение). Работает на localhost и на сайте по https.

## Ключи

Ключи хранятся в `.streamlit/secrets.toml` (этот файл не загружаем в GitHub). Пример — `.streamlit/secrets.toml.example`: скопируйте его, назовите копию `secrets.toml` и вставьте свои ключи.
```toml
AI_API_KEY = "ключ_модели_ИИ"
AQICN_TOKEN = "ключ_aqicn"   # реальные датчики, бесплатно: aqicn.org/data-platform/token
```

## Важно про данные

Open-Meteo в Казахстане считает воздух по модели CAMS квадратами примерно 45 км.
Это расчёт, а не замер конкретного датчика, поэтому сравниваем города, а не районы.
Время в графиках — местное время выбранного города.
