# Тестирование — Талшын, Баха, Макс

## Ручная проверка сайта

Сайт: https://air-control-sensors-t36qs5mspwqzwnkrithhj7.streamlit.app

Тестировщики проверяют его по общему **чек-листу** (31 проверка, у каждого свои строки:
Баха — выбор места и телефоны, Макс — AQI, погода, советы и графики, Талшын — карты,
темы и надёжность). В колонке «Результат» ставим ✅ или ❌, при ошибке пишем,
что случилось, на каком телефоне и в каком браузере. Ссылку на чек-лист даёт общий капитан.

## Скрипты

Запускать из папки проекта.

| Скрипт | Что делает |
|---|---|
| `python tests/check_ai.py` | Проверяет советы ИИ по шагам: ключ, библиотека `openai`, ответ модели, функция `get_ai_advice`. В конце — «[4] Всё работает!» |
| `python tests/compare_cities.py` | Печатает цифры приложения для 5 городов (AQI по модели и по живым датчикам, PM2.5, погода), чтобы сравнить с iqair.com и погодными сайтами |

## Что уже проверено

- **Приложение не ломается:** без интернета на сервере — демо-данные с предупреждением;
  поиск «ыыыы», одна буква, пустой поиск — понятное сообщение; запрет местоположения —
  понятное сообщение и кнопка «Обновить местоположение».
- **Сравнение с сайтами (16 ноября, 23:00):** погода близка к Tengrinews (разница 1–2 °C);
  влажность у модели бывает выше. AQI по живым датчикам в Караганде — 121, у IQAir — 127,
  а модель показывала 51.

Важно: без интернета на телефоне сайт не откроется — так устроены все сайты.
